# Contributing

Issues are welcome: a bug you hit, a screen that reads badly, a deployment step
that did not work the way this repository says it does. Say what you did, what
happened, and what you expected.

Before opening a pull request, run the Checks section of the README. That is
the lint, the type check, the test suite and the audits, and it is the same set
CI runs, so a green run locally is a green run there.

One focused change per pull request, and one commit per change with a literal
title saying what changed. A title that describes the work is easier to find a
year later than one that describes the intent.

Contributions are licensed AGPL-3.0-or-later, the same as the rest of the
project. Opening a pull request is how you agree to that.
